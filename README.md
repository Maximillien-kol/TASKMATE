# TaskMaster - Combined Landing & Dashboard

A complete task management application combining a beautiful marketing landing page with a powerful AI-powered task dashboard.

## Features

### Landing Page
- Beautiful hero section with animations
- Feature highlights
- Live AI demo powered by Gemini
- Customer testimonials
- Call-to-action sections

### Dashboard (Taskmaster)
- AI-powered task parsing with natural language
- Smart task breakdown
- Priority management
- Collaborative features
- Daily AI insights
- Visual analytics with charts

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `API_KEY` environment variable to your Gemini API key (optional for testing)
3. Run the app:
   `npm run dev`

The app starts on the landing page. Click "Get Started" to navigate to the dashboard.
